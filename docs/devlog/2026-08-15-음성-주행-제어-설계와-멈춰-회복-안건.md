# 음성 주행 제어(취소·일시정지·재개) 설계와 "멈춰" 회복 비용 안건

- 날짜: 2026-08-15
- 저장소: vica-voice-llm (PR #2 ← #3 ← #4 ← #5 스택)
- 관련: 젯슨 실측 보고 아티팩트(음성 지연), `docs/handoff-gpt-realtime-test.md`

## 결정 사항

### 1. LLM 백엔드에 OpenAI 선택 경로 추가 (PR #4)

모델 7종 같은 세션 벤치(세트 6종×3회)에서 gpt-5.4-mini 가 지연 중앙값
0.92초·꼬리 1.86초·판정 18/18 로 현행 gemma4:cloud(0.95초, 꼬리 7.95초)를
앞섰다. `VICA_LLM_PROVIDER=openai` 로 선택하며 기본값은 ollama(동작 불변).
**이 실측으로 gpt-realtime 도입 검토는 중단** — REST 가 목적(왕복 단축)을 이미
달성했다. 유료 4종(deepseek-v4-flash·glm-5.2·kimi-k3·k2.6)은 Ollama 구독
필요로 미실측, qwen3.5(0.8b·2b)는 Ollama format 강제를 무시해 탈락.

### 2. 음성 주행 제어 intent (PR #5)

cancel/pause/resume 을 "LLM 은 제안만" 원칙으로 추가:

- **확인은 위험 방향에만**: 임무를 버리는 cancel 과 움직임을 시작하는 resume 은
  고정 문구로 되묻고 "네"를 코드가 검증(자물쇠 1), 실행은 관리자 앱과 같은
  MissionCommand 서비스로 Mission Manager 가 판정(자물쇠 2).
- **서는 방향(pause)은 되묻지 않는다**: 로봇이 움직이며 "잠시 멈출까요?"라고
  되묻는 것은 현장에서 부자연스러웠고, 오분류해도 잠시 서는 것뿐(안전한 실패).
- 명백한 발화("취소해줘", "잠깐만")는 긴급어 필터와 같은 원칙으로 룰이 0초에
  잡고, 간접 표현("아 됐어, 안 가도 돼")만 LLM 이 분류한다 (실측 확인).
- 확인 문구는 자가 각성 실측으로 선정: "잠시 멈출까요?" 2/2 미감지, 대조군
  "멈춰 주세요" 2/2 감지. ("일시정지할까요?"는 긴급어 '정지' 포함이라 배제 —
  이후 pause 무확인 전환으로 이 문구 자체가 불필요해짐.)
- 첫 상호작용에서 로봇이 어휘를 가르친다(USAGE_GUIDE) — 어휘를 모르는
  사용자는 본능적으로 "멈춰"를 쓰기 때문.

## ROS 쪽 요구사항 (미구현, 협의 필요)

1. **pause 실행은 급정지가 아니라 짧은 거리 감속 정지**여야 한다 (급정지는
   E-stop 전용). "천천히" 감속 작업과 감속 프로파일을 공유할 수 있는지 검토.
2. 확정된 제어 intent → `/vica/mission/{cancel_destination,pause_navigation,
   resume_navigation}` 서비스 호출 연결 (앱과 동일 경로).
3. USAGE_GUIDE 의 ROS 인사 연결 — 진행 중인 웨이크워드 follow-up 작업과 결합.

## [안건] 음성 단독 원인 E-stop 의 회복 비용 (보류 — 추가 고민 중)

현장 대화 시험에서 확인: 사용자는 일시정지 상황에서도 "멈춰"를 쓴다.
"멈춰"=즉시 E-stop 은 설계 목표라 손대지 않지만, 현행 정책상 음성 E-stop 도
**관리자 앱 리셋**이 필요해 가벼운 "잠깐 멈춰줘" 한마디가 임무를 관리자 개입
전까지 세워 둔다. "잠깐 **멈춰**줘"류 발화는 어휘 교육으로도 못 막는다.

- 선택지 A: 음성이 유일한 원인인 래치는 완전 정지 후 음성 재확인으로 복귀
  허용 — **중앙 래치 정책([GAP] 보호 항목, emergency_stop_node) 변경**이라
  팀 합의 + 실기 검증 필요.
- 선택지 B: 현행 유지 — 운용 시 관리자 상주를 전제.

결정 보류. 논의 후 이 문서를 갱신한다.

## 추기 (같은 날 저녁) — 최종 실측과 RAM 주의

gpt-5.4-mini 구성으로 음성 세트(6종×3회) 최종 실측을 마쳤다. 체감 침묵
**음성 3.05초**(STT 1.07 + LLM 1.18 + 합성 0.84), 전체[버튼] 5.20초 — 최초
(08-13) 대비 각각 −3.2초/−4.5초. "취소해줘"는 룰 직행 0초로 확인 질문이
나갔다(PR #5 첫 실측). 이제 침묵의 최대 항목은 STT 다. 상세는 지연 실측
보고 아티팩트와 vica-voice-llm logs/.

**RAM 주의**: 파서의 로컬 ollama 경로는 keep_alive=-1 이라 gemma4:e2b
(7.2GB)가 상주한다. openai 백엔드 사용 중에도 떠 있어 RAM 피크 15.1/16GB
를 실측했다. 임시 조치는 `ollama stop gemma4:e2b`. OpenAI 도입 확정 시
"로컬 모델은 폴백 시에만 적재" 정책이 필요하다 — 실로봇에선 nav 스택과
메모리를 나눠 쓴다.
