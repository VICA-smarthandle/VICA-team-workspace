## 지금까지 확인된 능력 (2026-09-02 실기 기준)

음성 대화 한 바퀴가 완주됩니다.

```
"비카야"  →  "네?"
"화장실로 가자"  →  "화장실으로 안내해드릴까요?"
"그래"  →  주행  →  "화장실 앞에 도착했습니다.
                     다녀오시는 동안 여기서 기다릴까요?"
"그래"  →  "몇 분쯤 걸리실까요?"
"뭐 한 십 분"  →  "10분 대기하겠습니다"
```

한 번의 실기에서 목적지 3곳(화장실 → 방2 → 안내소)을 연달아 오가며
**11번 연속 발화가 전부 성공**했습니다. 그 밖에 확인된 것:

- 사람이 다가오면 로봇이 **먼저 말을 걸어** 안내를 제안합니다(카메라·YOLO)
- 주행 중 "멈춰" 같은 긴급어로 즉시 정지, 관리자 앱에서 해제
- 목적지는 관리자 앱에서 지도를 보며 등록·수정합니다
- LLM이 **용건을 장소로 추론**합니다 (실기 사례: "나 똥 마려워" → 화장실)

## 카메라 앞에서 위험한 것 (전부 실측된 것입니다)

1. **붙여 말하면 호출이 안 걸립니다.** "비카야 화장실로 가자"처럼 이어서
   말하면 웨이크워드 모델이 반응하지 않습니다 — 실기에서 41초 동안 0회.
   반드시 `"비카야"` → (로봇이 "네?") → 명령 순서로 **끊어** 말해야 합니다.
2. **STT가 같은 단어를 수십 번 반복해 적는 일이 있습니다**(예: `화장실`×75).
   그때 **엉뚱한 목적지로 갈 수 있습니다**(화장실 → 화장실2). 미수리입니다.
3. **조사 오류** — 로봇이 "화장실**으로** 안내해드릴까요?"라고 말합니다.
4. **마이크(reSpeaker)가 USB 레벨에서 굳으면** 소리가 아예 안 나고 안
   들립니다. 그 상태로는 촬영이 불가능합니다. 뽑았다 꽂으면 복구됩니다.
5. **Nav2 초기 위치를 매번 사람이 찍어줘야 합니다.** 안 찍으면 "안내를
   시작합니다"라고 **말만 하고 안 움직입니다.**
6. **카펫 주행 리스크**가 있습니다(기존 기록).

상세 근거는 아래 두 문서에 있습니다.

- `devlog/2026-09-02-체계적-실기-4종과-사망층-규명.md`
- `devlog/2026-09-01-귀-전쟁-실측과-수리.md`

## 촬영 계획

### 공통 — 지도를 새로 만듭니다

현재 지도(`vica_map_0630`)를 쓰지 않습니다. **촬영 장소에서 매핑을 새로
하고, 목적지도 새로 찍습니다.** 그래서 촬영 준비의 첫 단추가 매핑입니다.

참고로 기존 지도에 등록돼 있던 목적지는 입구 · 화장실 · 안내소 · 휴게실 ·
방1~3 이었습니다(이름 감각을 잡는 용도로만 참고).

### (1) 학교 — 확정

### (2) 병원 — 협조되면 촬영

목적지 이름과 **용건 어휘**를 새로 짜야 합니다(예: "나 수납해야 해" →
원무과). 장소마다 "그곳에서 하는 일"을 별칭으로 달아 두면 LLM이 용건만
듣고도 목적지를 고릅니다.

### (3) 짐 배달 — 바구니 장착

로봇에 바구니를 달고 "이거 가져다줘" 같은 요청을 촬영합니다.

**바구니는 차체 밖으로 튀어나오지 않습니다** — Nav2의 차체 크기(footprint)
설정을 바꿀 필요가 없다는 뜻입니다. 다만 무게와 무게중심은 달라집니다.

## 부탁드릴 것

이 세 축의 촬영 시나리오를 제안해 주세요. 원하는 것은 이렇습니다.

- **컷 단위로** 무엇을 말하고 무엇이 보이는지
- 각 컷이 로봇의 **어떤 능력**을 보여주는지
- 위 "위험한 것"을 피해 가는 **촬영 순서와 대사**
- **촬영 전 준비 목록** — 매핑, 목적지 등록, 용건 어휘 추가, 하드웨어
- **2일이라는 일정** 안에 셋 다 가능한지, 안 되면 무엇을 덜어낼지

시나리오를 정하기 전에 필요한 것을 저에게 먼저 물어보셔도 됩니다.

| 고친 것 | 결과 |
| --- | --- |
| 확인 질문의 "아니"가 통째로 증발 | 6/6 성공 |
| 창이 열린 동안의 재호출이 글자에만 의존(성공률 23%) | 소리로 판정 → 5/5 |

가장 큰 발견: **STT에 주던 힌트(initial_prompt)에 "고마워·다 됐어" 같은
종료·감사 표현이 들어 있어서, whisper가 짧고 애매한 소리를 그 문구로
메꾸고 있었습니다.** 하루치 오전사 11건이 전부 그 계열이었고, 그중 2건은
"안내 전체 종료"로 이어졌습니다. 그 표현들을 힌트에서 뺐습니다.

실기 도구도 만들었습니다 — `vica-voice-llm/scripts/ear_scribe.py`.
사람이 시험하고 프로그램이 회차별로 받아 적는 "서기"이고, 대본 6종
(호출·조기마감·에코·짧은답·거절·주행)이 들어 있습니다. 촬영 리허설을
기록할 때 그대로 쓸 수 있습니다.

**촬영 전 반드시 확인할 것**: 음성 노드 4개는 한 터미널
(`vica_voice.launch.py`)에서 같이 뜹니다. 마지막 수리가 반영되려면
재기동이 필요합니다. `.env`는 git 밖이라 젯슨 로컬에만 있습니다
