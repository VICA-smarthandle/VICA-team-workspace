# 2026-09-19 — LLM 클라우드→로컬 자동 전환(폴백) 실기 통과·dev 머지

## 결정

- 클라우드 LLM(gpt-5.4-mini)이 닿지 않으면 같은 발화를 로컬 Ollama 모델
  `gemma4-e2b-text`(Gemma 4 E2B 텍스트 전용 자작 변형)로 다시 처리한다.
- 클라우드가 살아나도 **해당 주행이 끝난 뒤(도착·실패·취소·귀가·idle)에만** 복귀한다.
- 로컬 모델은 필요할 때 적재하고 올라온 뒤엔 내리지 않는다. Ollama 서버는 음성 launch 가 띄운다.
- 사용자 멘트·앱 진단 표시는 두지 않는다. 앱 진단은 실기 중 철회했다 — 감시 노드가
  부품 단위 통과 코드만 앱에 올려 개별 문구가 전달되지 않았고, 통신이 끊기면 앱도
  끊기므로 별도 경고가 무의미하다(사용자 결정). 상태는 음성 노드 로그로만 남긴다.

## 저장소

- 음성 `vica-voice-llm` dev 3fd0bbc (feat/llm-local-fallback 머지, 시험 488 통과).
  정본 설계 `docs/superpowers/specs/2026-09-19-llm-local-fallback-design.md`,
  실기 기록 `docs/worklog-2026-09-19-llm-local-fallback-field.md`.
- ROS·앱 저장소 변경 없음. 폴백은 `.env` 의 `VICA_LLM_FALLBACK_MODEL` 로 켜고 끈다.
