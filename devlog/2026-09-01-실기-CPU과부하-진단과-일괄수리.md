## 2. 유령 비상정지의 해부 — 자동복구의 사각지대

부팅 자동복구는 정상 작동했다(17:33, 개입 0회). 문제는 그 다음:

```
17:34:00  감독 READY_TO_GO -> FAULT   (estop=False — 래치 없음!)
          원인: /emergency_stop 하트비트가 0.5초 안에 안 옴 (safety_gate "stale")
       -> ESTOP_RELEASED_WAIT_RESET ("정지 원인은 해소됐으나 관리자 초기화...")
       -> 자동복구는 침묵 — 래치가 안 걸렸으니 원인 목록이 비어 판정 불가
       -> 앱 비상정지를 눌렀다 풀어야만(정식 reset 절차 강제) 복귀
```

수리: `estop_timeout_sec` 0.5→2.0 (`5d3a980`). motor_can 3.0초와 같은 철학 —
순단은 참고, 진짜 두절에는 여전히 fail-closed. **감독 자체 FAULT 를 자동복구
범위에 넣을지는 미결** — 상향으로 빈도가 줄면 필요 없어질 수 있어 실기 후
재평가한다.

`state_stale` 경보의 정체도 같은 계열이다: `SAFETY_STATE_STALE` = 감독의 상태
방송 지각(프로세스는 3시간+ 생존). CPU 가 낮아도 노드 재시작·앱 재접속 순간의
DDS 연결 몰림으로 뜬다 — 8/28 가설 재확인. "미션이 자꾸 내려간다"는 감시
항목에 없는 전언이고, 오늘 3회 재시작은 전부 크래시 흔적 없음(사람 재기동).

## 3. task_fail 의 진짜 뜻

"목적지 도착 실패"가 아니라 **성적표를 주고받는 절차의 실패까지 전부 '실패'로
뭉뚱그려 보고**되는 것이다. bt_navigator 는 도착을 "Goal succeeded"로 6번
찍으면서도, 접수 대답이 20ms 안 오면(`default_server_timeout`) goal 을
ABORTED 로 마감했다. 20→100ms (`5d3a980`) — BT tick(10ms) 열 번 분량.

## 4. 일괄 수리 8건 (저녁, 사용자 승인)

1. `estop_timeout_sec` 0.5→2.0 — 2절
2. `default_server_timeout` 20→100ms — 3절
3. 라이다 점: **확정하면 함께 소멸**(8/31 '마지막 그림' 설계 철회 — 계속 떠
   있어 헷갈린다는 실기 피드백), 크기 1.6→0.8
4. 금지구역 그리기: 뗄 때마다 새 사각형이 쌓이던 것을 **미확정 초안 교체**
   방식으로 — 다시 끌면 초안이 바뀌고 [이 사각형 확정]으로만 목록에 들어간다.
   확정 없이 저장하면 초안을 확정으로 간주(그린 것이 소리 없이 버려지는 게
   가장 나쁜 실수 방식)
5. 홈 저장 빨간 화면(`_dependents.isEmpty`): 이름 대화상자의 컨트롤러를 퇴장
   애니메이션(~0.2초)이 끝나기 전에 dispose 하던 것 + 같은 찰나의 패널 철거
   겹침. dispose 를 애니메이션 뒤로, 정리를 다음 프레임으로. **좌표 저장
   자체는 원래 성공하고 있었다**(홈 복귀가 그 증거)
6. 상태 방송 10→2Hz: 소비자 전수조사(앱 마커·주행 버튼·keepout 유예) 결과
   주기에 민감한 곳 없음. 위치미확보 임계 3.0초 대비 여유 6배
7. 상태 노드 TF 청취기 → `/amcl_pose` 구독: 청취기는 /tf 전체(EKF 30Hz+)를
   상시 수신하는 최대 고정비. mission 이 먼저 쓰던 방식(transient_local).
   위치 확보 판정은 "정지 중엔 나이로 실효시키지 않고, 움직이는데 갱신이
   없을 때만 미확보"로 재설계 — AMCL 은 이동 중에만 발행하기 때문
8. pose_bootstrap 세션 게이트: 서비스가 불릴 때 스스로 scan·TF 를 열고(첫
   스캔 1.5초 대기 — MultiThreadedExecutor 라 가능) 5분 무사용이면 닫는다.
   지도는 원래 1회성(transient_local)이라 비용이 아니었다. 상시 16%→~1% 예상

덤: 초기위치 합격선 `MIN_SCORE` 70→65 — [TARGET] 절차대로 실기에서 확정.
정답 자리 주변인데 71부터야 통과했고, 주위 5m 가 트인 자리는 더 낮았다(먼
벽일수록 각도 오차가 큰 거리 오차가 된다). 낮춘 위험은 라이다 점 겹쳐보기로
사람이 이중 확인한다.
