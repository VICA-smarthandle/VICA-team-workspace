# 2026-09-02 — 체계적 실기 4종: 짧은 답이 죽는 층을 가렸다

어제까지는 "말이 씹힌다"를 로그를 뒤져 사후에 복원했다. 오늘은 **시험 서기**
(`ear_scribe.py`)를 만들어 사람이 회차를 찍고 프로그램이 받아 적게 했고,
대본 4종을 순서대로 돌렸다. 그 결과 **짧은 답이 죽는 층이 확정**됐고,
수리 2건이 같은 날 실기에서 검증됐다. 도구는 자동화가 아니다 — 시험은
사람이 하고 서기는 기록만 한다(발행 토픽 0개).

## 1. 도구 — 실기 서기

`vica-voice-llm/scripts/ear_scribe.py` (`7ae0123` 외 5커밋).
`vica_mark.py` 철학 그대로: 엔터로 회차를 찍으면 그 회차 동안
`/vica/wake`·`listen_state`·`user_text`·`intent`·`tts_*`·`/rosout` 에서
벌어진 일을 자동 귀속해 CSV 원자료와 devlog 용 표를 만든다. `.` 한 글자로
"대본대로 말했다"를 기록한다. 대본 5종(호출·조기마감·에코·짧은답·주행)에
순서·준비·회차별 대사·기대·주의가 박혀 있다.

순서 근거: **귀가 깨져 있으면 주행 시험이 헛수고다.** 제자리 3종 → 바퀴
띄우고 짧은답 → 바닥 주행.

## 2. 시험 결과

### 2-1. 호출 5회 — 통과

"네?" 5/5 재생(증발 0). 창 5/5 가 정확히 6.0초 유지. 매 회차 로봇의 "네?"
에코가 칩 VAD 를 속여 `창 speech` 도장을 찍었지만 **반짝 무효화가 전부
취소**했다 — 9/1 수리가 실전에서 5/5 로 작동한 실증이다.

### 2-2. 조기마감 5회 — 통과 + 결함 3건 노출

창 6.4~8.6초(6초 + STT 시간), 명령 5/5 접수. **조기 마감 0회.**
그러나 그 과정에서:

- **`아니`가 미션에 도달하지 못한다(3/3)** — STT 는 `아니.` 를 완벽히
  들었다. 지름길이 `clarify`(거절)를 만들고, 그 뒤의 "재청취 창 잡담은
  조용히 버린다" 필터가 `clarify` 를 잡담으로 오인해 삼킨다. 거절 멘트도
  안 나가고 미션은 `confirming` 으로 남는다.
- **로봇 자기 "네?" 에코가 승낙으로 읽혀 무확인 주행** — 전사
  `'네? 거기 어디 갔나 배아퍼'` → 첫 단어 `네` → 승낙 지름길 →
  `confirm=False` → 확인 질문 없이 출발(27초 주행 후 E-stop).
- 반복-나열 유령 `'화장실'×75` (기존 백로그 2번).

### 2-3. 에코 5회 — **자기증식 고리 확인**

3회차, 사용자는 첫 명령 뒤 완전 침묵인데 로봇이 스스로 운전했다:

```
사용자 "화장실로 가자" → 로봇 "화장실으로 안내해드릴까요?" 재생
  ↓ 에코 → 칩 VAD → barge-in (질문 중단, 재청취 창 열림)
  ↓ 말머리 소급이 로봇 질문 꼬리를 주움  ← 계측 대기 -0.24s (결정적 증거)
STT '화장실으로 안내해드리고.' → LLM navigate 화장실
  ↓ 미션 "같은 목적지 재제안 = 답" → confirm=True 인데 state=navigating
주행 시작 → 또 질문 재생 → 위로 되돌아감 (3연쇄)
```

**대기 -0.24초**는 발화가 창이 열리기 전에 시작됐다는 뜻이라 사람 말일 수
없다. 톱니 셋(칩 VAD 오판 · 말머리 소급 · 재제안=답)이 각각은 옳은
수리인데 에코 앞에서 서로를 밀어준다. barge-in 4회(사용자 침묵).
에코 필터는 전체 일치만 봐서 변형 3건(`안내해드리고`·`안내해 주세요`)이
통과했다.

### 2-4. 짧은답 30회 — **사망 층 확정**

**창·마이크에서 죽은 답은 0건.** 30회 전부 창이 열렸고(3.0~4.2초) 유령·
구제 기각도 없었다. 어제 가설("짧은 말은 마이크 문턱에서 죽는다 → KWS가
답")은 **반증됐다.** 죽는 곳은 그 다음 두 층이다.

| 단어 | 성공 | 죽은 층 |
| --- | --- | --- |
| 그래 | **5/5** | — (단어표에 있어 흔들리지 않는다) |
| 응 | 4/4 | — (오전사 '음'도 LLM 이 우연히 살림) |
| 네 | 3/4 | STT 오전사 → `다 됐어.` = **안내 종료** |
| 어 | 3/5 | 오전사 `이까랑.` → 무반응 / 웨이크 실패 |
| 대기해줘 | 3/4 | 오전사 `다 됐어. 고마워.` → **안내 종료** |
| 아니 | 1/4 | **LLM 층 `재청취 기각(무의미)` 3회** |

- **같은 소리가 운에 좌우됐다**: '응'을 whisper 가 `음`으로 적은 3회 중
  두 번은 `unknown` 으로 버려지고 한 번만 `affirm` 으로 살았다. `음` 이
  단어표에 없어 매번 LLM 에게 물었기 때문이다.
- **오전사가 하필 `finish`(안내 전체 종료)로 몰린다** — 되돌리기가 가장
  어려운 명령이다. 길이·음량으로는 못 가린다: 환각 발화 0.38~0.80초 vs
  진짜 짧은 답 0.40~0.64초로 완전히 겹치고 rms 도 비슷하다(실측).
- **취소가 조용히 실패한다**: "취소해줘" → "취소할까요?" → 답을 `음.` 으로
  오전사 → 기각 → 미션은 `navigating` 유지 → 다음 요청이 "지금 이동
  중입니다"로 막힌다. 사용자가 본 "취소했는데 또 취소하래"의 정체다.

### 2-5. 주행 3컷 — 수리 검증 + 종단 완주

**13회차에서 11번 연속 발화가 전부 성공**했다: 사람접근 수락 → 화장실
주행·도착 → 대기 → 재호출 → 방2 주행·도착 → "몇 분쯤?" → `뭐 한 십 분`
→ **wait 10분 추출** → 재호출 → 안내소 주행·도착 → 종료.

당일 수리 2건이 실기에서 확인됐다:

- 환각 필터 2회 차단 — `'고마워.'` 와 **`'고맙습니다. 고맙습니다.
  고맙습니다.'`**. 후자는 조각 판정이 없었으면 전체 불일치로 통과했다.
- `'어어.'` → LLM 없이 `navigate` 확정 (혼잣소리 단어표 작동).

새 결함 하나: **머뭇거림 접두사가 부정을 죽인다.**

```
전사 '아. 아니.' → 재청취 기각(무의미) intent=clarify
  → "응답이 없어 안내를 마치고 제자리로 돌아가겠습니다"
```

정규화하면 `아아니` 라 부정어 목록에 없다. 첫 단어 지름길은 **목적지 확인
질문일 때만** 돌고, 도착 후 대기 질문에서는 전체 일치만 본다.

기타: 사람접근 1회 오전사 실패(`다리.`), 에코 barge-in 1회, 주행 중
E-stop 1회, 조사 오류(`화장실으로`·`안내소으로`·`방2으로`).

## 4. 사고 — reSpeaker USB 먹통

주행 시험 직전 재기동 후 TTS·효과음이 전부 `Broken pipe [ALSA -32]`.
커널이 `usb 1-2.1: usb_set_interface failed (-32)` 를 반복했고 재생·캡처
스트림이 둘 다 `closed`, 웨이크워드 노드가 잡은 사운드 장치 0개 — **로봇이
못 듣고 못 말하는 상태**였다. 소프트웨어로는 못 푼다. 뽑았다 꽂아 USB
재열거(device 9 → 23) 하니 정상 복귀. 여전히 허브 경유(`1-2.1`)이고
커널에 `not running at top speed` 경고가 있다 — 재발하면 본체 포트로.

## 5. 수리 대상 (우선순위)

### A. 지금 고칠 것

1. **재청취 기각이 할 말을 든 사람까지 돌려보낸다** — 필터가 의도 이름
   (`unknown`/`clarify`)만 보고 `reply` 를 안 본다. 지름길이 만든 거절
   (`clarify` + CONFIRM_DECLINED)과 호출어 응답(`unknown` + "네?")이 같이
   삼켜진다. **`reply` 가 채워져 있으면 통과**시키면 두 결함이 한 번에
   풀린다. 근거: 조기마감 3/3 · 짧은답 3회 · 주행 1회.
2. **머뭇거림 접두사 부정** (`아. 아니.`) — 첫 단어 지름길을 목적지 확인
   질문 밖(도착 대화 등)에서도 부정에 한해 돌릴지 결정. 긍정은 이미
   `SOFT_AFFIRMATIVES` 를 첫 단어에서 뺐으므로 대칭이 맞다.
3. **에코 자기증식 고리** — 세 톱니 중 최소 하나를 끊는다.
   - (a) barge-in 이 연 창에서는 **말머리 소급을 끈다** (대기 음수 = 로봇
     소리라는 확정 신호가 있다)
   - (b) "같은 목적지 재제안 = 답" 을 **직전 발화가 로봇 질문 재생 중일
     때는 적용하지 않는다**
   - (c) 에코 대조를 전체 일치 → 부분 일치로 넓힌다 (변형 전사 대응)
