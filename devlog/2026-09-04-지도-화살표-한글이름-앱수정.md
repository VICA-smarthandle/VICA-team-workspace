# 2026-09-04 — 매핑 화면 로봇 화살표 · 한글 지도 이름 · 앱 조작 다듬기

한글로 붙일 수 있게 "사람이 읽는 이름"과 "기계가 쓰는 id"를 갈랐다. 전부 **실기

## 1. 매핑 미리보기 위 로봇 화살표 (ros2 cf4f7ec · 앱 c629818)

안 뜨던 이유는 두 겹이었다. 미리보기 지도의 id 는 `preview` 인데 `/robot_status`
의 map_id 는 map_server 가 없어 빈 값이라 `MapCanvas` 관문에서 걸렸고, 걸리지
않았더라도 위치가 `/odom` 좌표(AMCL 없음)라 엉뚱한 자리였다.

고친 길(A안): Cartographer 에 `publish_tracked_pose = true`, `map_preview_node` 가
`/tracked_pose` 를 받아 2초마다 나가는 미리보기 JSON 에 `robot_x/y/yaw` 를 동봉,
앱은 `poseArrow` 로 그린다. 새 위젯 없음. 대안 비교(rosbridge 직접 구독 100 Hz·
TF 청취기·PNG 에 그리기)는 노드 머리말에 있다. 화살표는 지도와 같은 2초 박자다.

## 2. 한글 지도 이름 (ros2 · 앱 · 루트 스크립트)

원칙: **id 는 영문 자동 생성, 표시 이름은 한글.** 병원의 환자 번호와 환자 이름이다.

| 자리 | 무엇이 흐르나 |
|---|---|
| 파일(.pgm/.png/.yaml)·URL·`VICA_MAP_YAML`·목적지 폴더·금지구역 파일 | id (`map_0904_151230`). 규칙 `^[A-Za-z0-9_-]+$` 그대로 |
| `maps/<id>.meta.json` | `display_name` (한글) — 유일한 저장소 |
| 지도 목록 `map_name` · 앱 화면 · 터미네이터 배너 | 표시 이름 |
| 사람이 적는 자리(`VICA_MAP_ID`, goto/initpose, 번호 메뉴) | 둘 다 됨 → `scripts/vica_map_resolve.py` 가 id 로 변환 |

- `plan_map_save`: 영문 이름은 옛 규칙(`lobby` → `lobby_0904`), 그 밖은 표시 이름 +
  `map_<MMDD>_<HHMMSS>`. NFC 고정(macOS 자모 분해 대비). 40자·경로문자 거부.
- 변환기는 한 곳뿐이다. 터미네이터 rc 템플릿·`vica_goto.sh`·`vica_set_initial_pose.sh`·
  번호 메뉴가 전부 그것을 부른다. 변환기가 실패하면 rc 는 옛 방식으로 내려간다.
- **CURRENT_MAP 의 뜻이 바뀌었다(A안).** "마지막 저장 성공"에서 "로봇이 쓸 지도 한
  곳"으로. 저장 성공 때 자동 갱신은 그대로이고, 사람이 다른 지도를 띄우고 싶을 땐
  `python3 scripts/vica_map_pick.py` 로 번호를 골라 갱신한다. 앱의 '(현재)' 표시,
  nav2·mission·app·initpose·goto 가 전부 같은 파일을 읽어 어긋나지 않는다.
- 이름표 없는 옛 지도 14개는 id 가 그대로 이름이다.

심사용 근거(왜 id 를 한글로 안 하나): OS 별 한글 정규화(NFC/NFD) 불일치, URL·셸·YAML
세 층의 이스케이프, 정규식이 곧 경로 이탈·명령 주입 울타리, 로그·bag·CLI 추적성.

## 3. 앱 조작

- 텔레옵 버튼: 누르는 동안 진해진다. 근거는 버튼 눌림이 아니라 provider 의 실제
  명령(`isTeleopHeld`) — 연결이 끊겨 명령이 안 나가면 색도 꺼진다. 덤으로 끊김 때
  `notifyListeners()` 누락으로 '이동 중'이 남던 것을 고쳤다.
- 지도 점: 폰 앱만 2/3(`kIsWeb` 기준), 점·테두리·화살표에 한 배율. 누를 수 있는 점
  (저장 장소)만 투명 판 16 px 를 깔아 고르기는 그대로다.
- Flutter 3.44 assertion(카드 안 ListTile 잉크)으로 매핑 화면 시험 전부가 죽던 것을
  `Material(transparency)` 한 겹으로 풀었다. 다른 화면의 같은 실패는 남아 있다.

## 3-1. 지도 이름 바꾸기 (앱 `지도 관리` 카드)

삭제 카드를 '지도 관리'로 넓혀 위에 `표시 이름` 입력칸을 뒀다. 노드의 `/rename_map`
(`RenameMap.srv`, **vica_interfaces 재빌드 필요**)이 `maps/<id>.meta.json` 만 고친다.
다른 지도가 쓰는 이름·이름표 없는 옛 지도의 id 는 거부(터미네이터 이름 선택의
유일성), 비우면 id 로 복귀. 옛 지도 14개에 한글 이름을 붙이는 것도 이 칸에서 한다.

## 4. 실기 전 할 일

1. ros2: 로봇 체크아웃을 app-ux 로 → `colcon build --packages-select vica_interfaces vica_cartographer`
   (RenameMap.srv 가 새로 생겨 인터페이스 재빌드 필요) → 매핑 스택·⑪ app 재기동.
2. 앱 다시 굽기(폰 APK · 웹). 웹은 `web/index.html` 이 로컬 CanvasKit 을 쓰므로 옵션 없음.
3. 터미네이터 rc 는 재생성했다(`~/.config/vica-terminator`). 떠 있는 칸은 옛 rc 라
   다시 띄워야 한다.
4. 확인 항목: 매핑 중 화살표 2초 갱신 · 한글 이름 저장 → 앱 목록·터미네이터 배너 ·
   `vica_map_pick.py` 로 옛 지도 선택 → nav2/mission/app 이 같은 지도인가 ·
   폰에서 점 크기와 고르기.
