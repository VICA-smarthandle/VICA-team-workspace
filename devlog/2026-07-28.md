# 개발 로그 2026-07-28 — TONY0043 (음성·웨이크워드)

## 요약

vica-wakeword 단계 0b 학습을 GPU 로 전환하고, 같은 설정 3회 학습으로 재현율이
안정적임을 확인했다. torch 2.13 ONNX 내보내기의 사이드카 함정을 발견해 절차를
보강했고, 실시간 청취 데모 도구를 추가했다.

## GPU 학습 전환

- `.venv-train` 의 torch/torchaudio/torchcodec 을 CUDA 빌드로 교체
  (`requirements/train.lock.txt` 갱신). train.py 는 CUDA 자동 감지라 코드 변경 없음.
- 학습 시간: CPU 약 20분 → **GPU(RTX 4070 Ti) 7분 30초**.
- 세 패키지는 같은 인덱스(CPU 는 pytorch cpu 인덱스, GPU 는 PyPI)에서 함께
  설치해야 한다. 섞으면 torchcodec 로드 실패.

## ONNX 사이드카 함정 (중요)

torch 2.13 exporter 가 가중치를 `<모델>.onnx.data` 사이드카에 분리 저장하고, 다음
학습이 이를 덮어쓴다. `.onnx` 만 이름을 바꿔 보존했던 1·2회차 학습본이 이 때문에
조용히 깨졌고(오탐 48/48 로 발견) 가중치가 소실됐다. 대응:

- `experiments/stage0b/consolidate_onnx.py` 추가 — 학습 직후 자립형으로 합침.
- 보존·배포·Jetson 이관 전 반드시 이 스크립트를 거치도록
  `docs/setup-pc.md`·`docs/stage0b-findings.md` 에 절차 명문화.
- 깨진 학습본 2개는 복구 불가능해 삭제했다. 성능 측정값은 측정 시점에 유효했고
  3회차로 재현되므로 결론에는 영향 없다.
