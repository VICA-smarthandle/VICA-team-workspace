## 1. 공통 뿌리 — 새 스피커

스피커 교체로 출력이 커지자 에코가 AEC 한계를 넘었고, 잔여가 세 층을
동시에 오염했다: ① 칩 VAD 가 에코를 "말"로 오판(barge-in 자책골 12회
전수 확인 — 사용자는 로봇 말을 끊은 적이 없다) ② 열린 창에 에코가
수음돼 유령 전사("생각 중" 운율이 '2, 3, 2, 3…' 숫자 세기로!) ③ STT
귀띔(CONFIRM_HINT)의 단어를 유령이 베낌 — 반복 등장하던 '고마워'와
'빨리 고. 대기.'의 정체(로봇 발화 전수 대조로 확정).

## 2. 실측 — 어림값을 숫자로 바꿈

- **doa_probe**: 핸들 위치 중앙값 180° (표본 33, 범위 8°) → 관문 복원값
- **mic_probe 신설**: VAD·DOA 실황 + ● 연속 구간 채증. 에코의 VAD 구간
  **전부 ≤0.14초** (로봇 단독 발화 조건) vs 진짜 발화 최단 **0.48초**
  (실기 계측 15표본) — 반짝 무효화 문턱 0.32초의 근거
- 수음 품질: 근접 발화 peak 1.00·clip — 오전사 재료. AGC 0.010 이
  에코까지 2배 증폭 → 0.007 로 인하(사용자 결정)
- **멈칫 채증 프로브 신설**(vica_stutter_probe): cmd_vel 끊김 epoch 를
  STT 계측과 대조하는 도구. STT 실측 98회·최대 3.7초(GPU) — Jetson
  통합 메모리 대역 경합 가설. 안전핀: int8_float16 + 음성 renice

## 4. 성과

- 관문 ON 구간에서 에코발 barge-in **0회** (OFF 구간 3회와 대조)
- 10회 명령 시험: 채택 7/10 (전날 사실상 0/10). "말했는데 빈 창" 유령
  소멸, 에코·환각 기각 필터 정상 작동 확인
- **두 시나리오 첫 완주**: 사람접근(질문→수락→회전→온보딩→주행→도착→
  대화→대기) + 각성 후 안내소 주행

## 5. 남은 것

1. **한 호흡 호출** — "비카야 화장실로 가자"를 붙여 말하면 웨이크 모델이
   못 뗌 (창이 열려 있을 땐 우연히 접수됨). 웨이크 모델 축 큰 주제
2. 반복-나열 유령 필터 ('방1×N', '2,3,2,3…') — 정규식 후보
3. 자유 창의 로봇 발화 전체일치 에코 기각 ('네?' 에코가 '네'로 접수)
4. 자모(발음) 유사도 복원 ('안내보러'→'안내소') / n-best / 스트리밍
   STT(sherpa-onnx 한국어) 조사 완료 — 단계표 있음
5. 웨이크워드 종료 시 크래시(exit -6, SIGABRT) — 무해하나 기록
6. [TARGET] 실사용 확정: 최소 개방 2.5 · 반짝 문턱 0.32 · AGC 0.007
7. "화장실으로" 조사 오류 (백로그 기존 항목)
